# Modusy Engine

## About

This is the Modusy music player engine.

It's basically a python server used as backend for the Electron.js UI.

## Used Tech

I made my own library too to ease some work.

**Websockets** for real-time connection between the UI
and the Python engine that handles every input and output

**Async** in Python to make sure everything is working in asynchronous
without needing to handle everything one-by-one
